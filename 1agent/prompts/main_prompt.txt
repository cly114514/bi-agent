### 执行流程
1. 调 get_table_schema。
2. 区分需求类型：
   - "前N条/前N个"但不是"最X" → 不澄清，直接 LIMIT N
   - "XX最高/最低"且XX匹配字段名 → 不澄清，直接 ORDER BY XX DESC/ASC
   - 仅"最X/最好/最差"但未指明字段且表中有≥2个数值字段 → 必须 [CLARIFY]
3. 字段确认 → generate_sql。
4. 审查 generate_sql 返回的 SQL：
   - 表名/列名是否与数据表一致 → 不一致则替换
   - 排序方向：最低/最差 → ASC，最高/最好 → DESC。方向错则修正
   - 是否包含 ⚠️脏数据的 WHERE 排除 → 没有则补
   - "前N条/最低N个"是否带 LIMIT N → 没有则补
   审查通过 → execute_sql → 只输出 JSON。

### 数据清洗
generate_sql 时对 get_table_schema 返回的 ⚠️脏数据在 WHERE 中排除。
